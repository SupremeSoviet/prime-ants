# 08. Интерфейс (планшет колонии), сеть и команды

> Сырая выгрузка со ссылками на код: `raw-extraction/04-items-ui-commands.md` (разделы 10–13).
> Код старого мода: `client/screen/ColonyStatusScreen.java` (1309 строк), `network/ColonyUiSnapshot.java`, `network/*Payload.java`,
> `command/FormicCommands.java`.

## Коротко

- **Один экран «Журнал колонии»** с 8 разделами: Обзор, Постройки, Заявки, Наука, Торговля, Инстинкт, Справочник, Отношения.
- Визуально задумка R3 почти достигнута: граф исследований, двухколоночный рынок, карточки помощи, EN/RU, «стеклянный» стиль.
- **Функционально много дыр:** планшет показывает одну колонию, а кнопки действуют на другую; карточки заявок врут о цене;
  рынок показывает недоступное как доступное; журнал событий не показывается вовсе; экран статичный и ставит одиночную игру на паузу.
- Сеть устроена как «снимок состояния + намерения» (сервер решает всё). Схема хорошая, но без проверки прав и без id колонии.
- **13 команд без проверки прав**, включая разрушительную `/formic qa scene`: она удаляет все колонии и выравнивает местность
  в любом мире.

## Как открывается экран

- Любой путь идёт через сервер: он присылает полный снимок колонии, клиент открывает новый экран.
- Откуда: яйцо матки (Обзор), планшет (Обзор, **самая старая колония мира**), блоки колонии (вкладка по типу блока: рынок →
  Торговля, архив → Наука, святилище → Отношения, остальные → Постройки или Обзор), муравей (Обзор), ответ на любое действие.
- **Снимок статичный**: нет живого обновления, прогресс и ресурсы замирают до следующего ответа сервера.
- **Экран ставит одиночную игру на паузу** (метод паузы не переопределён), вместе с симуляцией колонии.
- **После любого действия экран пересоздаётся**: сбрасываются вкладка, панорама карты исследований, страница рынка и выбранная цель.
- Горячей клавиши нет.

## Оболочка и стиль

- Концепция из комментария класса: «современное полупрозрачное рабочее пространство колонии». Тёплый янтарь только для фокуса
  и идентичности, «спокойное графитовое стекло» для информации.
- Панель занимает до 92% × 90% экрана, слева навигация (118 или 92 px), справа содержимое. Поверхности со срезанными углами (2 px),
  градиенты, тень, внутреннее свечение.
- Палитра: светлая подложка (мир виден), панель графитовая, акцент янтарный `#FFC56B`, текст кремовый.
- Цвета ресурсов: пища `#91C46C`, руда `#B9B8AC`, хитин `#D6B16E`, смола `#D69042`, грибы `#9BC76C`, яд `#7DD66C`, знания `#B58BFF`.
  Цвета каст: матка `#F0C26E`, гигант `#D06B5D`, мажор `#D99555`, солдат `#C15D48`, шахтёр `#A9A9A9`, разведчик `#8EC8D6`, рабочий `#D8B57A`.
- Иконки — рендеры ванильных и модовых предметов (пшеница для пищи, сырое железо для руды и т. д.).
- Все надписи обрезаются с «...». Сокращение названий до первого слова даёт двусмысленности вроде «Pheromone > Chitin».

```
+----------------------------------------------------------------------------------+
| [знак] <имя колонии>                           ( Культура · Отношение )       [X] |
+-------------+--------------------------------------------------------------------+
| РАЗДЕЛЫ     | [Еда 120][Руда 20][Хитин 24][Смола 24] ...  (только Обзор и Постройки)
| |Обзор      | <Заголовок раздела>                                                |
| |Постройки  |  содержимое раздела                                                |
| |Заявки     |                                                                    |
| |Наука      |                                                                    |
| |Торговля   | [полоса действий: кнопки инстинкта / цели и действия дипломатии]    |
| |Инстинкт   |                                                                    |
| |Справочник |                                                                    |
| |Отношения  | Колония #1   Реп 0   Радиус 18                    ▌тост-сообщение   |
+-------------+--------------------------------------------------------------------+
```

## Разделы

| Раздел (RU / EN) | Что показывает | Действия | Проблемы |
|---|---|---|---|
| **Обзор** / Overview | баннер личности и отношения, «Цель: текущая задача»; до 6 строк (задача, последнее событие, рабочая сила, текущая стройка, главный дефицит, исследование, матка); фишки населения | — | видны только 4 касты из 7 (нет мажоров, гигантов, матки); строка матки выпадает, когда строк 7 |
| **Постройки** / Buildings | карточки зданий и очереди: иконка, имя, уровень, статус (Запланировано / Строится / Готово / Улучшено / Повреждено / Ремонт / В очереди), прогресс | — | не больше 10 карточек даже в две колонки |
| **Заявки** / Requests | карточки помощи: «Еда для Рынка», «8 пшеницы даёт 12 еды», награда «+3 токен, +2 реп, П2», кнопка «Помочь», прогресс | клик по карточке выполняет контракт | **цена показана за одну пачку, а списывается вся недостача**; сортировка клиента ломает серверный приоритет; причина заявки не показана |
| **Наука** / Tech | граф из 7 узлов в 2 колонки со стрелками; цвет по состоянию; инспектор при наведении (камера, предшественник, цена) | перетаскивание, колесо, ПКМ сброс; клик по доступному узлу запускает исследование | позиции узлов захардкожены; «доступно» только если ресурсы уже есть, поэтому ветку «открыть заявки на ресурсы» можно вызвать только командой |
| **Торговля** / Trade | баннер последнего каравана или подсказки; две колонки: «Запросы колонии» (sell) и «Товары колонии» (buy); карточки «вход → выход» | клик по доступной карточке совершает обмен; колесо листает | предложения, закрытые репутацией, выглядят доступными |
| **Инстинкт** / Instinct | 4 строки приоритетов с полосками 100 / 75 / 50 / 25% | 4 кнопки: Еда / Руда / Хитин / Оборона | — |
| **Справочник** / Guide | 8 однострочных глав с пометкой «Откр. / Закр.» | — | содержания нет, всё открыто сразу |
| **Отношения** / Relations | до 4 известных колоний с состоянием и полоской; выбранная цель; стоимость действий | до 5 кнопок целей, 3 кнопки действий (Посол, Дань, Перемирие) | подстрекательство и военный пакт недоступны; стяги и скидки не показаны; действия доступны без известных колоний (сервер выберет любую) |

**Нет раздела «События»**, хотя README и чек-лист плейтеста его упоминают: журнал событий передаётся, но не рисуется.
Также передаются, но не показываются: ранг, здоровье матки, причина заявки, стоимость стягов.

**Виджеты:** своя кнопка `FormicButton` на `AbstractWidget` (в 1.21.11 у `AbstractButton` метод отрисовки `final`, поэтому
ванильную кнопку перекрасить нельзя). Два стиля: вкладка и действие. Карточки кликаются через списки хитбоксов, которые
пересобираются каждый кадр. Состояние «отключено» не используется, озвучки и клавиатуры у карточек нет, ванильных подсказок нет.

**Урок из прошлой сессии Claude** (`original/claude-memory/formic-tablet-ui.md`): когда пользователь сказал «уродливо, переделай
с нуля», градиенты поверх ванильных кнопок не помогли. Главным источником уродства были серые «каменные» ванильные кнопки на
фоне нарисованной панели и разбалансированная раскладка. Помогли полностью самодельные виджеты и честный расчёт раскладки сверху вниз.

## Подписи в мире

Над покоями матки и зданиями висят текстовые подписи (`TextDisplay`): имя колонии, личность и отношение, статусы зданий
(«Ремонт N%» и т. п.). У матки видимое имя. Подробнее в `04-buildings-and-nest.md`.

## Сеть

| Канал | Направление | Данные | Откуда | Обработчик |
|---|---|---|---|---|
| `colony_ui` | сервер → клиент | весь снимок колонии | открытие экрана и ответ на любое действие | открыть экран |
| `contract_request` | клиент → сервер | id контракта | карточка заявки | выполнить контракт (радиус 128) |
| `trade_request` | клиент → сервер | id предложения | карточка торговли | обмен (радиус 96) |
| `priority_request` | клиент → сервер | id инстинкта | кнопки инстинкта | сменить приоритет (радиус 96) |
| `diplomacy_request` | клиент → сервер | id действия + id цели | кнопки отношений | дипломатия (радиус 128) |
| `research_request` | клиент → сервер | id узла | узел графа | исследование (радиус 128) |

**Снимок** содержит 28 полей: id, имя, вкладку, тост, культуру, личность, отношение, ранг, задачу, матку, репутацию, радиус,
строки обзора, 7 ресурсов, 7 каст, здания, заявки (с ценой, пачкой, приоритетом, наградой), 7 исследований, торговлю,
последний караван, инстинкты, 5 действий дипломатии, известные колонии, 8 глав гайда и журнал событий. Формат ручной
(VarInt, строки, списки), без версии протокола и лимитов размера.

**Проблемы сети:**
1. Колония, которую показывают, и колония, на которую действуют, разные: планшет показывает первую, действия идут в ближайшую,
   радиусы 96 и 128 разные. В пакетах нет id колонии.
2. **Нет авторизации вообще:** ни владельца, ни проверки союза. Игрок может управлять исследованиями, инстинктом и торговлей
   чужой или дикой колонии, просто стоя рядом.
3. Нет проверки, что экран открыт, и нет ограничения частоты: модифицированный клиент может слать что угодно.
4. После каждого клика пересылается весь снимок.

## Команды

Корень `/formic`. **Проверки прав нет ни у одной команды**: всё доступно любому игроку, включая выделенный сервер.

| Команда | Что делает |
|---|---|
| `/formic colony create` | создаёт союзную колонию у источника команды (с расчисткой местности в радиусе 72) |
| `/formic colony dump` | печатает состояние **первой** колонии |
| `/formic colony renovate` | пересобирает ближайшую колонию (≤ 160): расчистка, заново все здания, дороги, узлы |
| `/formic colony tick <1..10000>` | прогоняет `ticks / 20` проходов всех колоний |
| `/formic colony instinct <id>` (алиас `priority`) | переносит инстинкт наверх у ближайшей колонии |
| `/formic colony seed-rivals <1..6> <32..256>` | создаёт колонии-соперники по кругу (единственный источник вражды) |
| `/formic colony resource set <тип> <число>` | задаёт ресурс **первой** колонии |
| `/formic ant spawn <каста>` | спавнит муравья касты |
| `/formic trade <offer>` | обмен с ближайшей колонией |
| `/formic research <node>` | запуск исследования (единственный путь к ветке «открыть заявки») |
| `/formic diplomacy <action>` | дипломатия (единственный путь к подстрекательству и военному пакту) |
| `/formic qa scene <name>` | **разрушительная QA-постановка**: удаляет **все колонии мира**, выравнивает квадрат радиусом 58–136 (при первом запуске до потолка мира), переводит игрока в режим наблюдателя |

## Что взять в перезапуск

- **Информационную архитектуру**: постоянная навигация по разделам, **карта** исследований с рёбрами и инспектором,
  двухколоночный **рынок** (запросы колонии и товары колонии) с баннером контекста, **карточки помощи** с доставкой и
  наградой, селектор инстинкта из 4 кнопок, главы гайда с условиями открытия, список отношений с выбором цели.
- **Визуальный язык**: полупрозрачное графитовое стекло поверх мира, янтарь только для фокуса, срезанные углы, единые цвета
  ресурсов, каст и состояний, иконки предметов везде.
- **Сеть «снимок + намерения»** с сервером как источником правды. Но добавить id колонии и версию протокола, проверять права
  на каждый запрос, обновлять вживую или дельтами, сохранять состояние клиента между обновлениями.
- **Урок про виджеты**: сразу свои самодельные виджеты, никаких перекрашенных ванильных кнопок.

## Открытые вопросы для перезапуска

1. Один экран-журнал или несколько экранов (стол колонии, рынок с ячейками, карта исследований)?
2. Должен ли экран работать без паузы и обновляться вживую?
3. Кто может управлять колонией: только основатель, союзники, любой рядом стоящий?
4. Нужен ли настоящий рынок с ячейками инвентаря вместо кнопок-«намерений»?
5. Отладочные команды: только для операторов и только в dev-сборке?
