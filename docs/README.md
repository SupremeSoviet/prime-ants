Пакет собран 25.09.2026 из старого проекта Prime Ants (внутреннее имя Formic Frontier, mod id `formic_frontier`), который делался
в апреле–июле 2026 моделями GPT 5.4 / 5.5, GLM 5.2 и Opus 4.8. Цель пакета: начать мод с нуля, ничего не потеряв из задумки,
контента и набитых шишек.

**Где старый код:** ветка [`archive`](https://github.com/SupremeSoviet/prime-ants/tree/archive) на GitHub (коммит `75a70f7`
от 13.07.2026) и локальная папка `C:\Users\user\Documents\Codex\2026-04-26\new-chat`.

## Как устроены разделы

- Текст на русском, игровые id и термины на английском (`queen_egg`, `chitin_farm`) и русские названия из локализации.
- Каждый раздел идёт по схеме: **коротко → как было в старом моде (с цифрами) → проблемы → что взять в перезапуск → открытые вопросы**.
- Все числа из кода на коммите `75a70f7`. Оценки и выводы без запуска игры помечены («по модели», «вероятно», «не проверено»).

## Главное в пяти пунктах

1. **Замысел сильный**: живое муравьиное поселение в духе Millénaire с кастами, экономикой, исследованиями, дипломатией, торговлей, рейдами и монументальным муравейником.
2. **«Живости» не получилось**: колония — это числа, мобы — декорация, и они не связаны. Темп сломан: без игрока «Цитадель» примерно за полминуты, дальше бесконечный рост.
3. **Много систем без исхода или недостижимых**: война только командой, караваны никуда не ходят, большинство событий — декорации, стадии невидимы.
4. **Лучшее, что стоит забрать**: чертежи построек (JSON-IR плюс компилятор плюс тесты формы), контракты, табличные основы механик, информационная архитектура планшета, язык состояний работы муравьёв.
5. **Процесс подвёл**: самооценка агентов, игнорирование упавших тестов, тесты на координаты, постановочные скриншоты. Лучше всего сработали маленькие вертикальные срезы «одно семейство на коммит».
